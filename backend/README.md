# Tokamak physics backend

Python қызметі: токамак физикасының модульдері, модельдерді таңдау
механизмі және HTTP API. Браузердегі 0-өлшемді модель (`js/physics.js`)
ITER-дің Q=10 нүктесін 1 % дәлдікпен қайта шығарады; бұл бэкенд оның
қамтымайтын физикасын қосады — нағыз тепе-теңдік, 1-өлшемді тасымал,
шеткі қабат, қашқын электрондар, отын циклі.

## Іске қосу

```bash
pip install -r requirements.txt
uvicorn api.main:app --reload --port 8001
# құжаттама: http://localhost:8001/docs
```

## Тексеру

```bash
python -m tokamak.validation     # жарияланған мәндермен салыстыру
python -m pytest tests/ -q       # 99 тест
```

## Модельдерді таңдау

`GET /models` таңдауға болатынның бәрін дереккөзімен бірге қайтарады.
Әр сұраныс қай модельді қолданатынын атайды, әр жауап оны қайтарып
көрсетеді — нәтиже әрқашан өзін тудырған болжамдарды алып жүреді.

* **Ұстау**: `ipb98y2`, `ipb98y1`, `iter89p`, `st`, `kz1`
* **L–H шегі**: `martin08`, `martin08_ra`, `kz_lh`
* **Тасымал**: `scaling_anchored`, `gyrobohm`, `bohm_gyrobohm`, `cgm`

## KZ-1 — осы жобаның моделі

IPB98(y,2) ε = a/R ≈ 0.1–0.35 аралығында фиттелген. Сфералық торлар
ε ≈ 0.8-де отыр және өрістен мүлдем басқаша тәуелді: Ip^0.57 B^1.08,
ал IPB98-де Ip^0.93 B^0.15. Бір де бір жарияланған скейлинг ITER мен
NSTX-ті бірге қамтымайды.

KZ-1 екі режим арасындағы **көрсеткіштерді** логистикалық функциямен
араластырады:

```
w(ε) = 1 / (1 + exp(-(ε - 0.55) / 0.05))
α_I = 0.93 − 0.36 w     α_B = 0.15 + 0.93 w
α_P = −0.69 − 0.04 w    α_n = 0.41 + 0.03 w
C   = 0.0562 · K^w
```

Фиттелетіні — бір ғана сан, `K`, ол импорт кезінде NSTX анкерлік
нүктесінен шешіледі. Қасиеттері:

* ε = 0.32-де (ITER) w = 0.010 → IPB98(y,2)-мен 2 %-ға дейін бірдей;
* ε = 0.79-да (NSTX) өлшенген ұстауды береді;
* ε бойынша үзіліссіз және монотонды, сондықтан A = 2 машина жартылай
  түзету алады, құздан құламайды.

**Не емес**: бұл регрессия емес, бір нүктеге бекітілген интерполяция.
ST тармағында B^1.08 тұрғандықтан, анкердің 0.45 Тл-інен әлдеқайда
жоғары экстраполяциялау көрсеткіш белгісіздігін толық көтереді.
Дұрыс нұсқа үшін ITPA H-режим базасына ST жазбаларымен бірге көп
машиналы фит керек.

## МГД тұрақтылық модулі

`mhd.py` — редукцияланған, бірақ **кері байланысы бар** модуль: ол тек
шектерді есептеп қоймайды, тұрақсыздықтар есептің өзіне әсер етеді.
`/stability` эндпоинті бір жұмыс нүктесін толық талдайды.

**Не есептеледі**

| Мода | Модель | Шешуші физика |
|---|---|---|
| Ideal kink / Тройон | β_N ≤ 4 lᵢ | ток профилінің шыңдылығы шекті көтереді |
| RWM | C_β = (β_N − β_no-wall)/(β_ideal − β_no-wall) | қабырға бетаны ~30% көтереді, бірақ тек өз резистивті уақытына дейін |
| Баллондық | s–α: α ≤ α_crit(s, κ, δ) | күшті үшбұрыштылық бірінші және екінші тұрақты аймақтарды жалғайды |
| **NTM** | модификацияланған Резерфорд теңдеуі | **табалдырықты есеп**: `w/(w²+w_d²)` формасы — тұқым арал `w_d`-дан кіші болса, жазылып кетеді |
| Пилообразный | Кадомцев қайта қосылуы | `r_mix` — спираль ағыны жабылатын радиус, фиттелген сан емес |
| ELM | педесталды толтыратын қуат балансы | басу тек өлшемді жиілікке айырбастайды — орташа қуат сол күйінде |
| VDE | κ мен lᵢ бойынша тік тұрақтылық қоры | — |

**Неге NTM ең маңыздысы.** Ол бета шегі емес, **табалдырық** есебі:
тұқым арал маргиналды еннен (ITER-де ~2 см) кіші болса, бутстрап
драйві классикалық тұрақтандырудан тез құлайды да, арал жазылады.
Сондықтан NTM тек бетаны төмендетумен емес, **триггерді болдырмаумен**
(пилообразный құлау, ELM) басқарылады. Модуль осыны қайта шығарады:
β_p = 0.65-те 2/1 модасы қозбайды, β_p ≈ 0.73-те табалдырық ашылады,
β_p = 1.0-де 8.8 см-ге қанығады, ал `j_cd = j_bs` ECCD оны толық басады.

**Пилообразный периоды — резистивті, ұстау уақыты емес.** Құлау q = 1
ішіндегі токты жазады, ал келесісі ток диффузиямен қайта тіктелгенше
бола алмайды: `τ_saw ~ C μ₀ r₁²/η(r₁) · (1 + c_f f_fast)`. ITER үшін бұл
~85–100 с, ал ұстау уақытына негізделген баға ~3 с береді — 30 есе
қате. Жылдам альфа-бөлшектер ішкі кинкті тұрақтандырып, периодты одан
әрі ұзартады («монстр» пилообразный) — дәл сол себепті ITER-де құлау
NTM үшін өте жақсы тұқым болып саналады.

**Кері байланыс.** `solver.py` ішінде: пилообразный құлау профильдерді
`r_mix` дейін жазады және 2/1 бетіне тұқым арал қалдырады; арал өз
ішінде χ-ні 30 есе көтереді; `w > 0.35 r_s` болса — құлыпталған мода
арқылы дизрупция; `C_β > 1` болса — RWM арқылы дизрупция.

**Не ЖОҚ.** Идеал МГД меншікті мәндер шешушісі (DCON/GATO типті),
Мерсье мен резистивті интерченж критерийлері, тороидалды мода
байланысы, peeling-ballooning-тің n-спектрі. NTM коэффициенттері
(`a_bs`, `a_gg`) — әдебиеттегі типтік мәндер, фиттелген емес.

## Калибрлеу мен фудж-коэффициенттің айырмасы

Бұл жобада бір рет фудж-коэффициент қойылған еді: `Q95_XPOINT = 1.109`,
q₉₅-тегі «жүйелі 8% кемістікті» жабу үшін. Ол кемістік физикалық емес,
**сплайн тегістеу қатесі** болып шықты — коэффициент бағдарламалық
қатені көрінбейтін етіп жасырып тұрған. Қате түзетілді, коэффициент
1.0-ге қайтарылды.

Қазір `pedestal.ALPHA_CRIT = 14.45` толық тізбек ішінде калибрленген
және ол **бір белгілі қалдықты сіңіреді**: бекітілген шекаралы ГШ
шешушісі q₉₅ = 3.11 береді (ITER-де 3.00, +3.7%), ал p_ped ~ q₉₅⁻⁴.
Айырмасы мынада — сіңірілген шама өлшенген:

```
14.45 / (3.1115/3.00)² = 13.43   ≈ 13.40 (қалдықсыз мән)
```

Бұл валидацияда **бөлек тексеру** ретінде тұр, ал q₉₅-тің өзі
+4% ауытқуымен көрініп тұр және еш жерде үнсіз түзетілмейді.
Калибрлеу — сіңірілген шама аталған, өлшенген және әлі де көрінетін
болғанда заңды; ол көріністен жоғалғанда фудж болады.

## Не валидацияланбаған

`validation.NOT_VALIDATED` тізімін қараңыз. Толық тізбекте **екі-ақ**
келтірілген тұрақты бар: ядролық тасымалдың критикалық градиенті
(R/L_T = 6.9) және педесталдың баллон табалдырығы (`ALPHA_CRIT`).
Екеуінің де масштабтауы калибрленбеген әрі өлшеніп расталады:
p_ped ~ Ip² және p_ped ~ B⁴ екі шектеудің қиылысынан өздері шығады.

79 тексерудің бәрі өтеді. q₉₅ тексеруі +4.2% ауытқумен өтеді:
оның шыдамдылығы 5% деп қойылған және түсіндірмесінде бұл бекітілген
шекаралы шешушінің белгілі қалдығы екені жазылған. Ауытқу жасырылмаған
— оны жабатын коэффициент бір рет қойылып, кейін бағдарламалық қатені
жасырғаны анықталған.

## Жабық контурлы басқару: симулятор + нейрожелі (`tokamak/control/`)

Плазманың орны мен пішінін ұстайтын нейрожелілік контроллер және оны
оқытатын жабық тұйықталған ко-симуляция. Төрт блок 1 кГц жиілікте
қатаң синхронды (lock-step) жұмыс істейді:

| Блок | Модуль | Не істейді |
|---|---|---|
| 1. Физикалық симулятор | `simulator.py`, `greens.py` | ГШ тепе-теңдігі → плазма жіпшелері; катушка / камера / плазма тізбегі; массасыз күш балансы |
| 2. Датчиктер мен кідіріс | `sensors.py` | FIFO кідіріс τ = 1–3 мс, гаусстық шу, интегратор дрейфі, қалыпқа келтіру |
| 3. Нейрожелі | `policy.py` | Actor πθ(A\|S), Critic Vφ(S), PPO + GAE, мінез-құлықты клондау |
| 4. Қауіпсіздік сүзгісі | `safety.py` | QP проекциясы: кернеу мен оның жылдамдығы, келесі қадамдардағы ток шегі |

`env.py` 1, 2, 4-блоктарды `reset()/step()` артына жинайды (сыйақы және
авариялық тоқтату сонда), `loop.py` кез келген контроллерді циклден
өткізеді және I/O келісімін анықтайды, `baseline.py` — салыстыру мен
клондауға арналған классикалық контроллер, `train.py` — оқыту,
`experiments.py` — мақаладағы барлық өлшем (жұптасқан сидтер, OOD плант,
кідіріс, сүзгі абляциясы, сызықтық шек).

### Математикалық аппарат

Тапсырмадағы формулалардың бір бөлігі мәтінде жоғалып кеткен; төменде —
кодта нақты іске асқан түрі.

**А) Тізбек теңдеуі.** PF катушкалары, орталық соленоид (CS), тік
тұрақтандыру жұбы (VS), вакуум камерасының 24 сегменті және плазма:

```
d/dt [ M(x) I ] + R I = V,     I = [I_coils, I_vessel, I_p],   V = [V_coils, 0, 0]
```

`M` — Грин функцияларынан (эллипстік интегралдар) алынған өзара
индуктивтілік матрицасы; тек плазманың жолы мен бағаны оның орнына
x = (R_c, Z_c) тәуелді. Теңдеу `M dI/dt` емес, `d(MI)/dt` түрінде
жазылған — қозғалып бара жатқан плазманың қозғалыс ЭҚК-і осында, ал
тік ығысуға қарсы итеретін камера тоқтарын дәл сол тудырады.

**Күш балансы.** Плазманың Альфвен уақыты ~1 мкс, басқару қадамынан үш
рет кіші, сондықтан плазма массасыз: x — динамикалық айнымалы емес,
мына теңдеулердің түбірі:

```
F_R = 2π Ip Σ_f w_f R_f B_Z,ext(f) + μ0 Ip²/2 · Λ = 0
F_Z = −2π Ip Σ_f w_f R_f B_R,ext(f)              = 0
Λ  = ln(8R_c / a√κ) + β_p + l_i/2 − 3/2
```

Созылған плазма Z бойынша **тұрақсыз** түбірде отырады; одан қашуды
камера L/R уақытына дейін баяулататын — индукцияланған камера тогы.
KTM үшін өсу жылдамдығы γ ≈ 79 с⁻¹ (сызықтық талдау 85 с⁻¹ береді,
тест 20 %-ға дейінгі келісімді тексереді). Интегралдау: имплицит Эйлер,
әр ішкі қадамда x бойынша хорда-Ньютон (жаңа тоқтар x-ке қатысты
сызықтық, сондықтан тек 2-өлшемді түбір ізделеді).

**Ә) Бақылау векторы.**

```
y_meas(t) = y(t − τ) + d·t + n(t),     n ~ N(0, σ²)
S_t = (y_meas − μ) / σ_s
```

`d` — ағын ілмектері мен магниттік зондтардың интеграторлық дрейфі
(эпизод сайын кездейсоқ), `μ` — t = 0 тепе-теңдігі, `σ_s` — әр арна
класының тұрақты физикалық масштабы. Ағын ілмектері өз орташасынан
айырма ретінде кіреді: CS рампасының ортақ ағыны оларды бірнеше жүз
миллисекундта шкаладан шығарып жіберетін еді. Желіге қосымша
(R−R_ref, Z−Z_ref, Ip−Ip_ref) қателері және алдыңғы әрекет беріледі.

**Б) Әрекет және QP сүзгісі.** A_t ∈ [−1, 1]^m,

```
V_target = V_ff + V_max ⊙ A_t
V* = argmin ½‖W (V − V_target)‖²,     W = diag(1/V_max)
     max(−V_max, V_prev − ΔV) ≤ V ≤ min(V_max, V_prev + ΔV)
     −I_max ≤ a + B V ≤ I_max          (I_coils(n+H) = a + B V)
```

`V_ff` — тепе-теңдік тоқтарын ұстайтын және плазманың кедергілік
кернеуін CS рампасымен беретін номиналды кернеу. Ток шегі H = 5 қадам
алдағы болжам бойынша қойылады. QP ADMM-мен (OSQP итерациясы,
адаптивті ρ) шешіліп, белсенді жиынтықта дәл шешіммен «жылтыратылады»;
кездейсоқ есептерде SLSQP-пен 1e-13 дәлдікпен сәйкес келеді (тест).
Кернеу шегі — қатаң; ток шегі орындалмайтын жағдайда әр жол қол
жететін аралыққа қиылады, сүзгі сәтсіздікке ұшырамай, қорек көзі
мүмкіндігінше кері итереді.

**В) Сыйақы.**

```
r = 0.4·exp(−(e_pos/1 см)²) + 0.3·exp(−(e_shape/1 см)²) + 0.3·exp(−((Ip−Ip_ref)/0.01 Ip_ref)²)
    − 0.1·‖A_t − A_{t−1}‖²/m − 0.1·‖W(V* − V_target)‖²/m − 50·[авария]
```

`e_shape` — изоағын шекара қатесі: мақсатты шекарадағы 16 нүктеде
`(ψ_k − ψ̄)/(2πR|B_p|)` метрмен, қатаң ығысу алынып тасталған (ығысу
`e_pos`-та бар). QP түзету мүшесі желіні сүзгі жөндеуі тиіс аймақтан
алыстатады.

**Г) PPO.**

```
L^CLIP = E[ min(r_t Â_t, clip(r_t, 1−ε, 1+ε) Â_t) ],   r_t = πθ(A_t|S_t)/πθ_old(A_t|S_t)
δ_t = r_t + γ V(S_{t+1})(1 − done_t) − V(S_t),         Â_t = Σ_l (γλ)^l δ_{t+l}
```

Уақыт шегіне жеткен эпизод V(S_T)-дан бутстрапталады; тек нақты авария
болашақты нөлдейді. Градиенттер қолмен жазылған және тестте ақырлы
айырымдармен тексерілген.

**Авариялық тоқтату.** d_min ≤ 2 см (қабырға), |dIp/dt| > 10⁷ А/с
(ток өшуі), |Z_c| > 0.30 м немесе күш балансының түбірі жоғалуы (VDE).

### I/O келісімі

| Бағыт | Құрамы | Бірлік | Формат |
|---|---|---|---|
| Симулятор → желі | [R_c, Z_c, I_p, I_coils(8), Ψ(12), B(16)] | м, м, А, А, Вб, Тл | 1D float64 |
| Желі → симулятор | [V_CS, V_PF1..6, V_VS] | В | 1D float64 |

### Оқыту тәсілі

1. **Классикалық контроллер** (`baseline.py`) — VS-ке тік ПД, PF-ке
   радиалды ПИ, CS арқылы Ip, VS тогын PF-ке түсіру. Оның күшейту
   коэффициенттері баптап қойылмаған, **жобаланған**: плант сызықтандырылады,
   кідіріс ығысу регистрі ретінде қосылады және барлық кідірістер (1–3 мс)
   мен төрт жұмыс нүктесінде тұрақты жиынның ең терең нүктесі таңдалады.
2. **Клондау** — актор оның әрекеттеріне, критик дисконтталған
   қайтарымдарға бейімделеді (шулы әрекеттермен жиналған демонстрация).
   Клондаусыз PPO-ны тексерген жоқпыз: ашық контурда плазма жоғалады, ал
   кездейсоқ бастапқы саясатпен тәжірибе қысқа, терминалмен аяқталатын
   эпизодтардан тұратыны күтіледі.
3. **PPO** — толық сыйақымен, кездейсоқ кідіріс, шу, дрейф, профиль
   оқиғалары мен тірек секірістерімен; ең жақсы бағаланған саясат сақталады.
   Үш нұсқа: `PPO-0` (плант рандомизациясыз, симметриялы критик),
   `PPO-DR` (плант рандомизациясымен: камера ×0,7–1,5, плазма ×0,5–2, қорек
   күшейтуі 0,85–1,15), `PPO-DR-AC` (рандомизация + привилегиялы күйді көретін
   асимметриялы критик; `--asymmetric`).

```bash
python -m tokamak.control.train --ppo-steps 100000 --asymmetric --out my_policy.npz   # PPO-DR-AC
python -m tokamak.control.train --ppo-steps 100000 --out my_policy.npz                # PPO-DR
python -m tokamak.control.train --ppo-steps 100000 --no-randomise-plant --out my_policy.npz   # PPO-0
python -m tokamak.control.experiments --out results.json --policy PPO-DR-AC=tokamak/control/policy_ppo_dr_ac.npz ...
```

Жіберілген салмақтар: `policy_ppo0.npz`, `policy_ppo_dr.npz`,
`policy_ppo_dr_ac.npz` (`policy.npz` — соңғысының көшірмесі; API-да
`policy`, `policy_ppo_dr`, `policy_ppo0`), оқу тарихы `training/`-те,
әр нұсқаның 0–2 сидтері мақала бумасында (`paper/policies/`).
`ml/train_all.py` өз нәтижесін `policy_pipeline.npz/json`-ға жазады (қысқа бір-сидті
оқыту; 30 сидте QP 51 % қадамда араласады, рандомдалған плантта тірі қалу 73 % —
тексерілген `policy_ppo_dr_ac.npz`-тен (93 %) нашар, сондықтан әдепкі емес).

|---|---|---|---|---|
| ПИД (жобаланған) | номиналды | 30/30 | 5,0 | 381 |
| PPO-0 (0-сид) | номиналды | 30/30 | 4,0 | 420 |
| PPO-DR-AC (0-сид) | номиналды | 30/30 | 6,7 | 385 |

Үш оқыту сиді бойынша (мақала, 4-кесте) **тұрақты** қалған бақылаулар:

* Қорек күшейтуі 1,3 болғанда (оқу ауқымынан тыс) PPO-DR және PPO-DR-AC
  барлық үш сидте плазманы ұстады, ал PPO-0 — үш сидтің біреуінде
  (эпизодтар 30-дан: PPO-0 — 0, 30, 0; PPO-DR — 30, 30, 30;
  PPO-DR-AC — 30, 30, 30).
* Номиналды плантта орта орын қатесі: PPO-0 — 4,8 мм, PPO-DR — 6,3 мм,
  PPO-DR-AC — 6,0 мм, ПИД — 5,0 мм: PPO-0 ПИД-пен тең, рандомизацияланған
  нұсқалар шамамен 1 мм нашар. **0-сидтегі PPO-0-дің ПИД-тен артықшылығы
  қайталанбады.**
* Камера кедергісі ×2 және датчик кідірісі 4 мс бойынша нұсқалар арасында
  жүйелі айырма жоқ (сидтер арасындағы өзгергіштік үлкен).
* **Асимметриялы критиктің пайдасы дәлелденбеді:** 0-сидте көрінген
  «сүзгіге тәуелділік азайды» әсері қайта оқытуда қайталанбады.
* QP-сүзгі ток шегінің бұзылуын азайтады, бірақ **кепілдік бермейді**
  (болжам плазма орнын қатырады): сүзгімен де VS катушкасында шектен
  бірнеше пайызға асу байқалады.
* ПД-контур 2 мс кідіріспен 192 с⁻¹ дейінгі тұрақсыздықты 1 кГц-те
  ұстайды (281 с⁻¹-ті ұстамайды); 10 кГц-те — 370 с⁻¹ (ұстамайтыны — 547).
  Шекті негізінен кідіріс анықтайды.

### Не модельденбейді

Плазма пішінінің қатаң ығысудан тыс өзгерісі (ГШ тек t = 0-де),
профиль эволюциясы (l_i, β_p тек сыртқы оқиғамен өзгереді), камерадан
басқа құрылымдардағы құйынды тоқтар, қорек көзінің кернеу шегінен тыс
динамикасы. Катушкалар жиыны — машинаға масштабталған **жалпы** схема,
нақты инженерлік геометрия емес; әдепкі параметрлер KTM-ге
(γ ≈ 79 с⁻¹) бапталған. Басқа дәстүрлі токамактар
құрылады, бірақ бапталмаған; сфералық торлар үшін генератор ашық қате
береді.
