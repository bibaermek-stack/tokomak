# Tokamak physics backend

Python қызметі: токамак физикасының модульдері, модельдерді таңдау
механизмі және HTTP API. Браузердегі 0-өлшемді модель (`js/physics.js`)
ITER-дің Q=10 нүктесін 1 % дәлдікпен қайта шығарады; бұл бэкенд оның
қамтымайтын физикасын қосады — нағыз тепе-теңдік, 1-өлшемді тасымал,
шеткі қабат, қашқын электрондар, отын циклі.

## Іске қосу

```bash
pip install -r requirements.txt
uvicorn api.main:app --reload --port 8001
# құжаттама: http://localhost:8001/docs
```

## Тексеру

```bash
python -m tokamak.validation     # жарияланған мәндермен салыстыру
python -m pytest tests/ -q       # 51 тест
```

## Модельдерді таңдау

`GET /models` таңдауға болатынның бәрін дереккөзімен бірге қайтарады.
Әр сұраныс қай модельді қолданатынын атайды, әр жауап оны қайтарып
көрсетеді — нәтиже әрқашан өзін тудырған болжамдарды алып жүреді.

* **Ұстау**: `ipb98y2`, `ipb98y1`, `iter89p`, `st`, `kz1`
* **L–H шегі**: `martin08`, `martin08_ra`, `kz_lh`
* **Тасымал**: `scaling_anchored`, `gyrobohm`, `bohm_gyrobohm`, `cgm`

## KZ-1 — осы жобаның моделі

IPB98(y,2) ε = a/R ≈ 0.1–0.35 аралығында фиттелген. Сфералық торлар
ε ≈ 0.8-де отыр және өрістен мүлдем басқаша тәуелді: Ip^0.57 B^1.08,
ал IPB98-де Ip^0.93 B^0.15. Бір де бір жарияланған скейлинг ITER мен
NSTX-ті бірге қамтымайды.

KZ-1 екі режим арасындағы **көрсеткіштерді** логистикалық функциямен
араластырады:

```
w(ε) = 1 / (1 + exp(-(ε - 0.55) / 0.05))
α_I = 0.93 − 0.36 w     α_B = 0.15 + 0.93 w
α_P = −0.69 − 0.04 w    α_n = 0.41 + 0.03 w
C   = 0.0562 · K^w
```

Фиттелетіні — бір ғана сан, `K`, ол импорт кезінде NSTX анкерлік
нүктесінен шешіледі. Қасиеттері:

* ε = 0.32-де (ITER) w = 0.010 → IPB98(y,2)-мен 2 %-ға дейін бірдей;
* ε = 0.79-да (NSTX) өлшенген ұстауды береді;
* ε бойынша үзіліссіз және монотонды, сондықтан A = 2 машина жартылай
  түзету алады, құздан құламайды.

**Не емес**: бұл регрессия емес, бір нүктеге бекітілген интерполяция.
ST тармағында B^1.08 тұрғандықтан, анкердің 0.45 Тл-інен әлдеқайда
жоғары экстраполяциялау көрсеткіш белгісіздігін толық көтереді.
Дұрыс нұсқа үшін ITPA H-режим базасына ST жазбаларымен бірге көп
машиналы фит керек.

## МГД тұрақтылық модулі

`mhd.py` — редукцияланған, бірақ **кері байланысы бар** модуль: ол тек
шектерді есептеп қоймайды, тұрақсыздықтар есептің өзіне әсер етеді.
`/stability` эндпоинті бір жұмыс нүктесін толық талдайды.

**Не есептеледі**

| Мода | Модель | Шешуші физика |
|---|---|---|
| Ideal kink / Тройон | β_N ≤ 4 lᵢ | ток профилінің шыңдылығы шекті көтереді |
| RWM | C_β = (β_N − β_no-wall)/(β_ideal − β_no-wall) | қабырға бетаны ~30% көтереді, бірақ тек өз резистивті уақытына дейін |
| Баллондық | s–α: α ≤ α_crit(s, κ, δ) | күшті үшбұрыштылық бірінші және екінші тұрақты аймақтарды жалғайды |
| **NTM** | модификацияланған Резерфорд теңдеуі | **табалдырықты есеп**: `w/(w²+w_d²)` формасы — тұқым арал `w_d`-дан кіші болса, жазылып кетеді |
| Пилообразный | Кадомцев қайта қосылуы | `r_mix` — спираль ағыны жабылатын радиус, фиттелген сан емес |
| ELM | педесталды толтыратын қуат балансы | басу тек өлшемді жиілікке айырбастайды — орташа қуат сол күйінде |
| VDE | κ мен lᵢ бойынша тік тұрақтылық қоры | — |

**Неге NTM ең маңыздысы.** Ол бета шегі емес, **табалдырық** есебі:
тұқым арал маргиналды еннен (ITER-де ~2 см) кіші болса, бутстрап
драйві классикалық тұрақтандырудан тез құлайды да, арал жазылады.
Сондықтан NTM тек бетаны төмендетумен емес, **триггерді болдырмаумен**
(пилообразный құлау, ELM) басқарылады. Модуль осыны қайта шығарады:
β_p = 0.65-те 2/1 модасы қозбайды, β_p ≈ 0.73-те табалдырық ашылады,
β_p = 1.0-де 8.8 см-ге қанығады, ал `j_cd = j_bs` ECCD оны толық басады.

**Пилообразный периоды — резистивті, ұстау уақыты емес.** Құлау q = 1
ішіндегі токты жазады, ал келесісі ток диффузиямен қайта тіктелгенше
бола алмайды: `τ_saw ~ C μ₀ r₁²/η(r₁) · (1 + c_f f_fast)`. ITER үшін бұл
~85–100 с, ал ұстау уақытына негізделген баға ~3 с береді — 30 есе
қате. Жылдам альфа-бөлшектер ішкі кинкті тұрақтандырып, периодты одан
әрі ұзартады («монстр» пилообразный) — дәл сол себепті ITER-де құлау
NTM үшін өте жақсы тұқым болып саналады.

**Кері байланыс.** `solver.py` ішінде: пилообразный құлау профильдерді
`r_mix` дейін жазады және 2/1 бетіне тұқым арал қалдырады; арал өз
ішінде χ-ні 30 есе көтереді; `w > 0.35 r_s` болса — құлыпталған мода
арқылы дизрупция; `C_β > 1` болса — RWM арқылы дизрупция.

**Не ЖОҚ.** Идеал МГД меншікті мәндер шешушісі (DCON/GATO типті),
Мерсье мен резистивті интерченж критерийлері, тороидалды мода
байланысы, peeling-ballooning-тің n-спектрі. NTM коэффициенттері
(`a_bs`, `a_gg`) — әдебиеттегі типтік мәндер, фиттелген емес.

## Калибрлеу мен фудж-коэффициенттің айырмасы

Бұл жобада бір рет фудж-коэффициент қойылған еді: `Q95_XPOINT = 1.109`,
q₉₅-тегі «жүйелі 8% кемістікті» жабу үшін. Ол кемістік физикалық емес,
**сплайн тегістеу қатесі** болып шықты — коэффициент бағдарламалық
қатені көрінбейтін етіп жасырып тұрған. Қате түзетілді, коэффициент
1.0-ге қайтарылды.

Қазір `pedestal.ALPHA_CRIT = 14.45` толық тізбек ішінде калибрленген
және ол **бір белгілі қалдықты сіңіреді**: бекітілген шекаралы ГШ
шешушісі q₉₅ = 3.11 береді (ITER-де 3.00, +3.7%), ал p_ped ~ q₉₅⁻⁴.
Айырмасы мынада — сіңірілген шама өлшенген:

```
14.45 / (3.1115/3.00)² = 13.43   ≈ 13.40 (қалдықсыз мән)
```

Бұл валидацияда **бөлек тексеру** ретінде тұр, ал q₉₅-тің өзі
+4% ауытқуымен көрініп тұр және еш жерде үнсіз түзетілмейді.
Калибрлеу — сіңірілген шама аталған, өлшенген және әлі де көрінетін
болғанда заңды; ол көріністен жоғалғанда фудж болады.

## Интеграцияланған есеп: ITER Q=10

Педестал биіктігі peeling-ballooning физикасынан, ядро — сол педесталдың
үстіндегі қатты тасымалдан, тепе-теңдік — Град–Шафранов шешушісінен.
Ешбір шама енгізілмеген, соның ішінде **H98 — шығыс**:

| Шама | Модель | ITER | Ауытқу |
|---|---|---|---|
| P_fus | 490 МВт | 500 | −2.1 % |
| Q | 9.79 | 10 | −2.1 % |
| W_th | 327 МДж | 325 | +0.6 % |
| τ_E | 3.71 с | 3.70 | +0.3 % |
| **H98** | **0.98** | 1.00 | **−2.3 %** |
| β_N | 1.79 | 1.77 | +0.9 % |
| q₉₅ | 3.12 | 3.00 | +4.2 % ← белгілі қалдық |
| Z_eff | 1.655 | 1.65 | +0.3 % |
| ⟨T_e⟩ | 8.59 кэВ | 8.9 | −3.5 % |
| ⟨T_i⟩ | 8.30 кэВ | 8.1 | +2.4 % |
| T_ped | 4.22 кэВ | 4.5 | −6.1 % |
| Гелий күлі | 4.37 % | 4.1 | +6.7 % |

Есеп МГД кері байланысымен жүреді: пилообразный құлау, аралдардың
эволюциясы және ELM циклі қосулы.

H98 = 0.98 — бұл **болжам**: модель ITER Q = 10-ға өзі жететінін және
ол үшін қандай ұстау сапасы керегін айтады, ал бұрынғы нұсқа оны
енгізілген шама ретінде алатын.

## Не валидацияланбаған

`validation.NOT_VALIDATED` тізімін қараңыз. Толық тізбекте **екі-ақ**
келтірілген тұрақты бар: ядролық тасымалдың критикалық градиенті
(R/L_T = 6.9) және педесталдың баллон табалдырығы (`ALPHA_CRIT`).
Екеуінің де масштабтауы калибрленбеген әрі өлшеніп расталады:
p_ped ~ Ip² және p_ped ~ B⁴ екі шектеудің қиылысынан өздері шығады.

79 тексерудің бәрі өтеді. q₉₅ тексеруі +4.2% ауытқумен өтеді:
оның шыдамдылығы 5% деп қойылған және түсіндірмесінде бұл бекітілген
шекаралы шешушінің белгілі қалдығы екені жазылған. Ауытқу жасырылмаған
— оны жабатын коэффициент бір рет қойылып, кейін бағдарламалық қатені
жасырғаны анықталған.
