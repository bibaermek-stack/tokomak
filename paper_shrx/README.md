# Мақала: SHRX — турбуленттік тасымалдың нейрожелілік моделі және TORAX-пен салыстыру

`article_kk.pdf` — қазақша ғылыми мақала (A4, Times-стильді қаріп, мәтін қара түсті ақ бетте, суреттер мен скриншоттар түсті; 25 бет шамасында), `article_kk.html` — сол мақала
(бір файл, KaTeX формулалары мен суреттері ішіне енгізілген). Мақаладағы **әр сан** `data/*.json` файлдарынан макросқа (`{{= … }}`) алынады:
қолмен жазылған нәтиже сан жоқ; макрос есептелмесе, құрастыру тоқтайды.

| Папка / файл | Мазмұны |
|---|---|
| `sections/*.md` | мәтін (Markdown + LaTeX формулалары), аңдатпалар (қазақша, орысша, ағылшынша), бөлімдер, қосымша |
| `build.py` | `sections` + `data` → `build/article_kk.html` → `article_kk.pdf` (pandoc + Node/KaTeX + Chromium); теңдеу, сурет, кесте, бөлім, әдебиет нөмірлеу |
| `refs.py` | әдебиеттер тізімі (мәтіндегі ретпен нөмірленеді) |
| `values.py` | мәтінге керек туынды сандар |
| `make_figures.py`, `figstyle.py` | суреттердің барлығы; ақ фон, қара мәтін мен осьтер, деректер түсті (Окабе–Ито палитрасы, түсті ажыратуы қиын адамдарға да қолайлы); сызық түрі мен маркер де әртүрлі, сондықтан сұр түсті басып шығаруда да оқылады |
| `screenshots/` | интерфейс пен API скриншоттары (түпнұсқа түсімен) |
| `tools/` | деректерді қатыру (`collect_*.py`), скриншот (`screenshots.py`, `screenshot_api.py`), көру (`preview.py`) |
| `data/` | тәжірибе нәтижелерінің қатырылған көшірмелері (JSON) |

## Қайта құру

```bash
cd paper_shrx
npm install                       # KaTeX 0.16.11 (build/ мен node_modules/ git-ке кірмейді)
python3 make_figures.py           # data/*.json -> figures/
python3 build.py                  # -> article_kk.pdf, article_kk.html (PDF үшін Chromium: build.py ішіндегі CHROME жолы)
python3 build_docx.py           # -> article_kk.docx (Word: формулалар — Word теңдеулері, суреттер — PNG; pandoc, python-docx қажет)
python3 build.py --draft          # деректер әлі келмесе: есептелмеген макрос [?] болып қалады (соңғы нұсқада рұқсат етілмейді)
```

Қажеттілігі: Python 3 (numpy, matplotlib, pillow; Word үшін python-docx), pandoc ≥ 3, Node.js, Chromium. Шрифт: Liberation Serif (Times-метрика), қазақ әріптері бар.

## Деректердің шығу тегі

`data/shrx_results.json`, `torax_results.json` — `docs/shrx/`, `docs/torax_comparison/` нәтижелері; `ensemble.json`, `uncertainty.json`, `inloop.json`,
`chaos.json`, `speed.json`, `db5.json`, `st_teacher.json` — `tools/collect_*.py` шығысы (бастапқы файлдар эксперименттер жүргізілген уақытша қалтада;
скрипттері `backend/ml/shrx/`, `backend/ml/shrx/db5/`, `backend/ml/shrx/st/` ішінде).

## Тексерілмеген және ескерілетін тұстар

* **Авторлар, ұйым, ақпарат** — `[…]` деп қалдырылған; «Қаржыландыру» және «Мүдделер қайшылығы» жолдары да толтырылуы тиіс.
* **Әдебиеттер тізімі** 19.10.2026 күні интернеттегі библиографиялық жазбалармен салыстырылды (авторлар, атауы, журнал, том, бет, жыл): қателер түзетілді
  (ITPA дерекқорына дұрыс сілтеме — Verdoolaege et al., 2021; Zanisi et al. — UKAEA репозиторийінің `CITATION.cff` бойынша; ойдан шығарылған «Paper 13368» алынды).
  Баспа сайттарының өздеріне қол жеткізу болмады, сондықтан беттері мен DOI жариялау алдында тағы бір рет қаралуы керек. ӘОЖ коды тексерілмеген.
* **TORAX салыстыруы** — бір ITER режимі, бір рет; тәжірибелік жазбалар бойынша TORAX тек «тексерілген» жазбалардың бір бөлігінде (қанша — кестеде) жүргізілді,
  TORAX баптауы бастапқы нұсқада (дөңгелек қима, тіркелген $q$), параметрлері түзетілмеді.
* **Сезімталдық:** қатаң машиналарда интегралды нәтиже бастапқы күйдің $10^{-12}$ ауытқуына сезімтал; бір жүгіру желіні салыстыруға жарамайды (мақаланың 4.3 бөлімі).
* **Сфералық токамактар / КТМ:** КТМ үшін желі жеткізілмейді; TGLFNN-STEP мұғалімінің оқу ауқымы SINTEZ-тің қазіргі КТМ күйлерін қамтымайды.
* Скриншоттар «СИНТЕЗ» веб-интерфейсінің (0-өлшемді, браузерде) және HTTP API-дің; нейрожелі тасымал веб-интерфейсте жоқ.
* Нәтижелер **тек симуляцияға** және ашық деректер қорының осы үлгісіне қатысты.
