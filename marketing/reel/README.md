# Жарнама роликі (Reels, 9:16, 18.3 с)

Сайттың өзінің нақты кадрларынан жиналатын жарнама видеосы: 3D токамак,
реактор ішіне ұшу, басқару кабинасы, диагностика панельдері. Құрылымы мен
типографиясы үлгі роликке сәйкес: hook → 01 → 02 → 03 → 04 → соңғы кадр.

| Уақыт | Бит | Кадр |
|---|---|---|
| 0–3 с | Hook | ландинг: жанып тұрған токамак, айналу |
| 3–6 с | 01 · 3D САЙТ | реактордың ішіне 7 секундтық ұшу (2× жылдамдықпен) |
| 6–9 с | 02 · НАҚТЫ ФИЗИКА | плазманың ішінде + модель шешетін теңдеулер |
| 9–12 с | 03 · ПЛАТФОРМА | басқару кабинасының панельдері |
| 12–15 с | 04 · ТОЛЫҚ ФУНКЦИЯ | диагностика тізбегі |
| 15–18.3 с | Соңғы кадр | бренд, тапсырыс батырмасы |

## Жинау

```bash
bash build.sh      # сайтты түсіру → монтаж → out/sintez-reel-silent.mp4
bash mux.sh        # қазақша озвучка → out/sintez-reel.mp4
```

Барлық мәтін `composer.html` ішінде, бір жерде: `BRAND` (соңғы кадр) және
`BEATS` (әр биттің мәтіні). Озвучка мәтіні мен уақыты — `vo_plan.json`.

## Неге сайт виртуалды сағатпен түсіріледі

Рендерер баяу кадрларға бейімделеді: алдымен ажыратымдылықты, сосын бүкіл
сапа деңгейін төмендетеді. Бағдарламалық рендерде (GPU-сыз) әр кадр
секундтап созылады, сондықтан кәдімгі экран жазбасы күңгірт әрі бұлыңғыр
шығады. `capture.js` уақытты өзі басқарады: `requestAnimationFrame` пен
`performance.now` ауыстырылады, `autoScale` өшіріледі, сапа бекітіледі —
әр кадр жылдам GPU-да қалай салынса, дәл солай салынады.

Екі түзету осы жерде ғана қажет:

- **Көру бұрышы.** Шейдердің проекциясы биіктікке нормаланған, сондықтан
  тік кадрда көлденең бұрыш 2.8 есе тарылады. Камераны артқа тарту
  болмайды — сәулелік жүріс 26 бірлікте тоқтайды — сондықтан FOV кеңейтіледі
  (сыртта ×1.8, плазмаға кірген сайын ×1.25-ке дейін).
- **8-биттік буферлер.** SwiftShader жартылай-float буферде бірнеше NaN
  пиксел қалдырады, ал bloom оларды mip өлшеміндегі қара блоктарға
  таратады. 8-биттік буферге жазғанда NaN нөлге айналады да, таралмайды.

## Озвучка

Piper TTS, ISSAI KazakhTTS моделінің `M1_Iseke` дауысы (ана тілінде
сөйлеушіден оқытылған ер дауыс, негізгі жиілігі ~119 Гц — үлгідегі
дауыспен бірдей). Әр жол үлгінің сөйлеу терезесіне жылдамдықпен
сыйғызылады, соңында −14 LUFS-ке келтіріледі.
