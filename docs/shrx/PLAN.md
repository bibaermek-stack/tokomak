# SHRX жоспары — SINTEZ тасымал моделін TORAX-тың QLKNN-інен «мықты» ету

Бұрынғы «TORAX стиліндегі нейрожелілік суррогат» енді **SHRX** деп аталады.
Алдыңғы салыстыру (`docs/torax_comparison/`) көрсеткендей, бастапқы нұсқа (**SHRX v0**) ITER-де
P_fus = 67 МВт / Q = 1,3 берді, TORAX — 532 МВт / Q = 10,6.

## «Мықты» дегеніміз не (алдын ала жазылған, өлшенетін критерийлер)

| № | Критерий | Табалдырық |
|---|---|---|
| K1 | Жылдамдық: бір шақыру, 26 және 65 нүкте | QLKNN-нен ≥ 2 есе жылдам |
| K2 | Дәлдік (QLKNN эталон): held-out R² (χ_e, χ_i, SI) | ≥ 0,98 |
| K2b | Бірдей күйлер A / B1 / B2: медиана SHRX/QLKNN; ×2 ішіндегі нүктелер; Пирсон r | 0,8–1,25; ≥ 80 %; ≥ 0,9 |
| K3 | Интеграцияланған ITER разряды: P_fus (SINTEZ + SHRX), ITER-ге ештеңе бапталмай | TORAX-тан (532 МВт) ±15 % |
| K4 | Тәуелсіздік: тек NumPy, JAX керек емес; барлық машинада істейді; ауқымнан тыс (OOD) белгісі | орындалады |
| K5 | Адалдық: PDF-те әр критерий бойынша орындалды/орындалмады | міндетті |

**Шектеу (ашық айтамыз).** SHRX-тың «мұғалімі» — QLKNN (Apache-2.0, TORAX-пен бірге жүреді), ол өзі
QuaLiKiz гирокинетикасының суррогаты. Сондықтан SHRX гирокинетикалық дәлдікте QLKNN-нен асып түсе алмайды;
«мықты» дегеніміз — **бірдей дәлдікте жылдам, тәуелсіз және SINTEZ-тің көпфизикалы (МГД, дизрупция,
дивертор, отын циклі) симуляторына кіріктірілген**. Гирокинетикалық дәлдіктен асу үшін QuaLiKiz/GENE деректері керек — бұл келесі кезең.

## Кезеңдер

0. **Атау.** `shrx` — ағымдағы нұсқа; `shrx_v0` — бастапқы (бұрынғы `neural_surrogate`), салыстыруды қайта жасау үшін; `neural_surrogate` — `shrx`-ке көрсететін ескі атау (тестер/API бұзылмасын). Белгілер, құжаттар, API жаңартылады.
1. **Көпір (bridge).** SINTEZ күйі → QLKNN кірісі (R/L_Ti, R/L_Te, R/L_ne, R/L_ni, q, ŝ, x, Ti/Te, log ν*, n_i/n_e) және QLKNN ағыны → SI χ_e, χ_i. NumPy, TORAX формулаларымен. **Тексеру:** TORAX-тың өз ішкі кірістерімен (медиана қате < 5 %) және `chi_turb`-пен (медиана ауытқу < 15 %) салыстыру.
2. **Деректер.** Нағыз QLKNN-ді (TORAX ортасы, JAX) бірнеше миллион нүктеде есептеу: SINTEZ-тің нақты разряд күйлері (әр машина, әр тасымал моделі) + градиентті ауытқыту + QLKNN ауқымындағы біркелкі қорап. Нысана — gyro-Bohm ағындары (q_e, q_i, p_e), TORAX-тағыдай қосылған.
3. **Оқыту.** JAX/optax (тек оқыту үшін), әр түрлі ені мен тереңдігі; нәтиже — NumPy салмақтары (жобаға қосылады). Дәлдік пен жылдамдықтың Парето-сы бойынша таңдау.
4. **Кіріктіру.** `transport_model="shrx"`: χ_e **және** χ_i модельден (бұрын χ_i әдепкі форма еді); ауқымнан тыс белгісі; бөлшек тасымалы бұрынғыша (D = 0,25 χ_e) — кейін қосуға болады.
5. **Бағалау.** Сол харнес: ITER разряды, A/B1/B2 күйлері, жылдамдық. K1–K5 бойынша есеп.
6. **Тесттер мен құжат.** QLKNN-ден алынған алтын мәндер (JAX-сыз тестілеу), API, README; жаңа PDF `docs/shrx/`.
7. **Commit + push** (PR жоқ).

Нәтиже критерийлерден аспаса — оны сол күйінде жазамыз.
